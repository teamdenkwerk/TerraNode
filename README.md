## 📌 Overview

**TERRANODE** integrates fragmented land and property information from multiple geospatial sources into a unified digital land representation.

It combines cadastral records, municipal GIS, drone imagery, GNSS/CORS data, building footprints, infrastructure, elevation data, and historical records.
